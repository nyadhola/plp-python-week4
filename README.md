# Week 4 Assignment: Functions in Python

## File Descriptions
- `welcome.py`: Defines a `welcome()` function that generates personalized welcome messages and calls it three times.
- `toolbox.py`: Contains three utility functions (`double`, `is_pass`, and `greet`) demonstrating basic arithmetic, comparison logic, and default parameter values.

## Reflection
The `greet()` function in `toolbox.py` was the hardest to write because it required understanding how default parameter values work when an optional argument isn't provided by the caller.
